# Sargon Science

مكتبة Sargon Science الرقمية.

## الملفات

- `index.html` — الصفحة الرئيسية وواجهة الموقع.
- `style.css` — التصميم والتجاوب مع الهاتف والكمبيوتر.
- `script.js` — الكتب والسلة والتقييمات وروابط الطلب.
- `README.md` — معلومات وتشغيل المشروع.

## المزايا المضافة

- إضافة الكتب إلى السلة.
- حذف كتاب محدد من السلة.
- تفريغ السلة بالكامل.
- حفظ السلة في `localStorage`.
- نظام تقييم من 5 نجوم لكل كتاب.
- حفظ متوسط التقييم وعدد التقييمات محليًا.
- زر واتساب في أسفل الموقع لفتح المحادثة مباشرة.
- زر تيليگرام في أسفل الموقع للانتقال إلى قناة Sargon Science.
- تصميم متجاوب مع الهاتف والكمبيوتر.
